ONE-OF-ONE is an original card duel game: beat Vex the Collector at 8000 Life to win the Last Wishblade, the one-of-one wish-forged card (3000 ATK, one copy in the whole game). Summon monsters across four elements (Flame, Tide, Gale, Stone), combine spells, and read the rival's announced intent each turn to counter it.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No network needed; keyboard (1-5 play card, A attack, Space end turn, Enter start, R restart) and mouse both work.
