ONE-OF-ONE is an original 3D card duel game on a night ferry: beat Marlow the Ferryman at 8000 Life to win the Genesis Coin, the one-of-one mythic crypto coin (3000 ATK, one copy in the whole game), the fare for the crossing. Every character is an invented crypto coin with a rarity trait — Common, Rare, Epic, Legendary, and the single Mythic Genesis Coin — across four coin families (Forge, Tide, Gale, Stone), each told apart by colour and shape. Combine protocol spells, and read the rival's announced intent each turn to counter it. Night-ferry table (moon, lanterns, water, deck planks), CSS 3D cards with big glowing family symbols, deal-in flip animations, full dawn-gold win and cold-steel loss screens.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No network needed; keyboard (1-5 play card, A attack, Space end turn, Enter start, R restart) and mouse both work.
